# Webix Lead Desk v0.33.2

Use the encrypted workspace OpenAI key for business and decision-maker searches. Search
requires a verified allowance and configured limits. Choose one active email campaign to
run daily discovery with a target of up to 50 new businesses.

Under **Connection settings**, you can enable AI assessments and drafts or delivery of
approved scheduled emails. Both settings start off. Mailbox readiness, sending limits
and message approvals still apply.

To update, stop the worker, close the app and run the installer under the same Windows
account. Your saved connection details, encryption keys and backups are preserved.
