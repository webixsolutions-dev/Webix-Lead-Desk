Backup and cutover

  1. Enable maintenance with the local administration command, stop the web and worker processes, and wait for their leases to expire.
  2. Create a new encrypted backup and verify it. Keep the backup key and original credential key privately, separately from the backup.
  3. Restore into an empty database on the same application version with live sending disabled. Row content, sender locks, suppression and approvals are checked.
  4. Check the restored workspace, then explicitly resume only the chosen target. Keep the original source in maintenance.

No data export or restore is available through this web page. Use the repository's docs/move-to-vps.md and docs/operations.md commands. The final owner setup checklist is in docs/owner-setup.md.
