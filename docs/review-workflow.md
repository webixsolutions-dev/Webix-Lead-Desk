# Review, conversation and booking workflow

1. Open **Outbox**. Each card shows the business, website and sources, what was and was not checked, the service hypothesis, and the exact recipient/sender/body/footer/signature. Expand collected details or open the full research record. Select only the exact revisions reviewed, then approve and optionally schedule up to 100. Editing creates a new unapproved revision.
2. **Settings → Email setup → Outreach approval** defaults to manual. The owner can delegate first contact, or first contact plus configured follow-ups, in selected campaigns with a daily automatic approval cap. Only drafts created after that choice qualify. Existing sender, contact-basis, suppression, threading, pilot, ramp, inbox freshness and delivery fences still apply. Any incoming email or recorded cross-channel reply disqualifies automatic outreach. Quotation/concept/reply approval can never be delegated. Mode changes revoke pending policy approvals.
3. **Inbox → Prepare / review reply** shows recipient-specific history. Edit directly or provide a rewrite instruction for the configured optional AI. No AI call runs without enabled funding/rates. Tick price inclusion only for a reply, supply the exact approved amount/currency/scope, and review the new revision. Prices are still prohibited in cold outreach.
4. **Bookings** stores proposed dates and timezones. Confirm only after checking the real host calendar and recipient agreement. Overlapping confirmed bookings for the same named host are blocked. Edits remove confirmation. Existing pipeline meeting notes appear on this board too. This release does not synchronize calendars, parse arbitrary natural-language dates, send invitations or promise host availability.
5. **LinkedIn → Activity** shows actual recorded invitations, acceptances, replies and named conversations. Staff perform invitations/messages in LinkedIn and record actual actions here. Log incoming replies promptly; they stop pending outreach and create review tasks. Profile OAuth is for posting, not inbox/connection automation. Never store account passwords or cookies.
6. **Writing & offers → Guidance scope** includes global, partner, conversation, LinkedIn and 26 industry records. Only matching industry context is sent to the model. Priors guide questions; actual evidence decides. Available campaign offers are considered across the catalogue, with ranked alternatives and a valid no-fit result. Paused services stay unavailable. No prices, proof, local staff or claims are fabricated.

## Boundaries and validation

Website checks fetch bounded HTML with existing SSRF/robots controls, extract public tool mentions and booking links, and record unknown visual/form/social/ad areas. Tool markup does not establish configuration or a working integration. Social/Maps/ad-library access needs an actual supported adapter or recorded human evidence; a link is not a completed audit. Proof remains owner-verified. Source text cannot publish guidance or approve a message.

The new controls have offline regression coverage for default/manual approval, policy revocation, incoming-response stops, exact digest batch approval, reply-only price permission, sender/recipient history isolation, timezone transitions, booking conflicts and page rendering. Live model quality, real calendar availability and provider integration are not established by these tests.
