# Set up writing and offers once

Open **Settings → Writing & offers**. Each section saves independently.

| Section | What to save | When it changes |
| --- | --- | --- |
| Global guidance | Tone, evidence rules, allowed claims and meeting approach | When your writing policy changes |
| Partner guidance | Agency/white-label-specific approach | When the partner offer changes |
| Campaign guidance | Extra rules for one audience | Only for that campaign |
| Services & offers | Service family, package, scope, availability and pricing | Add or edit packages any time |
| Verified proof | Real delivered work/results, source, attribution and matching services | When evidence or permission changes |
| Local team | Confirmed people available for meetings | Optional; add later |

Use **Custom quote** when price depends on discovery. Amounts remain empty; this does not mean
free. Choose **Fixed price** only after confirming both setup and recurring amounts. A confirmed
zero recurring component means no recurring fee. Currency and recurring period apply to this
offer only. Opportunity reports still use explicitly recorded CAD deal values.

Several packages can use the same service family: for example a website launch and a redesign.
Use package name and scope for their differences. The family stays stable after saving so campaign
and proof references keep matching. No offer prices are inserted into outreach drafts.

Proof should state exactly what can be demonstrated. A completed website is scope proof; it is
not evidence of additional sales. Record the actual agency/own-product attribution and permission.
Choose matching service names, with optional exact industry restrictions. A card without a service
or attribution stays outside new drafting briefs. Reconfirm the checkbox when editing a card.

In **Leads → Add leads → Create a campaign**, choose relevant saved services, industry,
city/state/province and country. **Results → Targeting** edits an existing campaign. Prefer a new
campaign for a materially different audience so outcomes remain comparable. Global guidance and
offers are reused. Country support is currently Canada/US; other countries need supported rules
and sending-time configuration, not just a different currency.

Update the Windows worker once for v0.23. Later changes to these saved settings do not require an
installer. Existing approved email content is unchanged; review new drafts before any send.
