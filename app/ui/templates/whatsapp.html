How review works

Each pending draft gets its own review code. Individual codes normally expire after 24 hours. Full alerts include the business, website, evidence excerpt, sender, recipient and email text. Open the review link to inspect the complete research, signature and any attachment before approving.

  • APPROVE code — approve and schedule that exact revision, subject to all current checks and sending limits.
  • REJECT code — reject that unsent draft.
  • EDIT code — get its dashboard editor, where you can edit or request a rewrite.

For an active campaign batch, send APPROVE by itself to approve its current first-contact drafts already shown in WhatsApp. Individual 👍 reactions approve their specific draft. Editing, a changed conversation or an expired code requires fresh review. Summary-only or oversized previews require dashboard approval.

New incoming emails create notifications. This integration does not send prospect emails itself, enable live sending, or read your other WhatsApp chats. Notifications are paced at one per worker poll; larger queues take longer.
