# Pipeline and reviewed concepts

Replies create internal review cards. An interested label sets a one-business-hour Calgary
handoff target (weekdays 09:00–17:00); it never qualifies a lead or authorizes a response.
An active team member records the need, assignee, next action, actual meeting time/link and
CAD setup/monthly values. Stage changes use a version check so concurrent tabs cannot
silently overwrite each other. Won/lost outcomes require a reason.

The owner can create homepage, service-page, AI-call-flow and portal concepts after human
qualification of a confirmed existing email conversation. Concepts reference recorded business
observations and contain only owner-written copy. They are illustrative, not working client
systems, and make no invented results or implementation claims. Editing means a new version.

Review the exact preview, then explicitly publish it to obtain an unguessable read-only link.
Set `PUBLIC_BASE_URL` to the deployed HTTPS origin first. Anyone holding a published link can
view that concept. Public pages omit internal evidence, contacts, mailbox details and controls;
they are noindex, escaped and uncached. Revoking the link disables access and blocks unsent
messages that reference it. Do not put confidential client information into public concept copy.
Server/proxy access logs must omit request URLs for these bearer links.

Concept approval and email approval are separate. Prepare a personal response containing the
exact link, review it in the normal draft editor, then approve and schedule it. The first sender,
recipient and subject remain locked; Message-ID references preserve the original thread.
A fresh reply cancels pending concept delivery, and the final pre-DATA check revalidates the
concept. The board records Demo sent only after known provider acceptance. All sender limits,
Calgary windows, contact evidence, suppression and pilot rules still apply.

The only automated follow-up step remains step 1. Owner-requested concept responses use
separate numbered steps and cannot restart an automated follow-up sequence.
