# Observed LinkedIn results and learning

Open LinkedIn → Results & learning. Owner sees all registered members; reviewers
see only their own profiles, posts and records, including when a profile is paused.
The six main owner navigation tabs remain unchanged.

## Weekly funnels

Choose a Calgary Monday. The report counts distinct people with actual confirmed
invitation or first-message touches in that week, not planned tasks or quota slots.
Acceptance uses the invitation cohort; replies, positive replies and meetings use
the first-message cohort and a 30-day response window. Outcomes after the selected
week can count if they have been recorded by the displayed as-of time. A reply before
contact cannot count, and repeated messages/replies cannot inflate the person count.
Pending invitations and SSI/warnings are current/latest observations, labelled as such.
A missing denominator is shown as unknown, not zero performance. Meetings count an
explicit recorded meeting_booked reply, not inferred interest or calendar availability.

## Profile health

The worker evaluates all active profiles each planning tick. Task planning and human
claiming also recheck the acceptance rule before release. Fewer than 20% acceptances
after at least 50 distinct invited people pauses the profile. Exactly 20% does not.
All observed invitations since the last owner resume review count, including pending
ones; there is no silent maturation exemption. This conservative internal rule is
not a claim about a LinkedIn-approved safe limit.

SSI and restriction notices are entered manually from the real member's account.
A reported current restriction sets the profile to restricted immediately. Paused
profiles cannot start actions or pass post-author approval checks. Existing records
and in-flight uncertain actions remain visible. Owner resume requires a factual
review note and confirmation that any actual platform restriction has been resolved.
It starts a fresh evaluation cohort without erasing historical outcomes, quotas,
approvals, contact cooldowns or suppression. The app cannot bypass platform restrictions.

## Angle comparisons

Only a confirmed first-message touch with an exact approved-draft fingerprint enters
the experiment table. Each person is attributed once to their earliest attributable
first-message angle. Draft snapshots retain the industry segment and warm/cold status;
legacy missing context stays unknown. Message length excludes the separate identity
footer. Invitation note/blank status and the actual Calgary send hour are retained.
Rows group the angle and these contexts; rates are distinct-person counts, not totals
of repeated replies. Results from another assigned member do not convert the original
member's angle.

A candidate leader requires at least two angles in the same segment, warm/cold,
length, invitation-note and send-hour group, at least 50 contacts for every compared
variant, known context and an untied positive-reply rate. This is an observed leader
for owner review, not a causal or statistical guarantee. Nothing changes automatically.

## Post observations

Each published post can receive cumulative impressions, reactions, comments, profile
views, target-buyer connection requests and target-buyer DMs, plus an attribution note.
The latest immutable snapshot is displayed; successive totals are never added.
No restricted analytics API or scraped personal profile data is assumed. The member
or owner supplies the observations. Unknown counts should be collected before saving;
zero means an observed zero. Post counts use the time publication was confirmed in
this app; historical posts without a recorded confirmation timestamp are not backdated.

## Fortnightly memory

Stable fourteen-day Calgary periods end on Mondays. Once a completed period contains
actual outgoing touches, the worker creates one pending Playbook proposal containing
profile counts and comparable angle evidence. Empty periods create nothing. Suggestions
use no API credits and cannot publish themselves. Owner can edit/apply or dismiss them
through the existing Learning review, which appends a Playbook version and preserves
history. Later LinkedIn draft suggestions and static creative briefs read approved
Playbook guidance. This is application memory, not autonomous model training.

Offline tests cover cohort deduplication and attribution, exact 49/50 and 20% boundaries,
manual snapshot isolation/immutability, same-context minimum samples, maintenance,
worker wiring and a proposal that remains inert until the owner applies it.
