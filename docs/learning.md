# Reviewed learning and memory

Learning & Memory collects suggestions when an internal user changes a first-contact draft,
the owner skips a draft with a reason, or a team member records a won/lost outcome. Each
suggestion keeps its source and before/after or outcome evidence. It does not affect drafting
until the owner reviews and applies the exact proposed addition.

Edit the suggested rule or example, review the current guidance, and check the confirmation.
Application appends a new Playbook version in that campaign's scope. The proposal decision and
guidance update are atomic. Another tab's edits cause a reload requirement; the suggestion is
not lost or partly applied. Dismissal preserves evidence and changes no guidance.

Published guidance is reused by both the copyable ChatGPT brief and optional API drafts.
It is persistent application memory, not model-weight training. No paid AI calls are necessary.
Website text and inbox replies cannot create or publish guidance. A recorded deal outcome is
one observation, not proof that particular wording caused the sale. Approved style examples
must not be reused as factual claims about another prospect.

Guidance history can restore an earlier version as a new current version. History is never
rewritten, and older approved drafts retain their exact body and original guidance references.
Only future drafts use the restored guidance. If a scope reaches 12,000 characters, consolidate
its current guidance in Settings before adding more examples.
