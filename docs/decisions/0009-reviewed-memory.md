# ADR: memory is reviewed versioned guidance

Context: Outreach should improve from owner edits without treating hostile website/email text
or one lucky outcome as authority.

Decision: Capture internal feedback as inert proposals. Apply only an explicit owner-reviewed
rule to the existing append-only Playbook, atomically with its review decision. Restore by
creating a new version. Keep all message approvals bound to their original content.

Consequence: Guidance persists without paid training. Human review remains necessary; past
results do not automatically change targeting, prices, sender policy or outgoing approvals.
